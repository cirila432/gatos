# 🐱 O Fascinante Mundo dos Gatos

## Descrição

Este projeto consiste em uma página informativa sobre gatos,
apresentando informações, curiosidades e cuidados importantes
para esses animais.

O projeto foi desenvolvido como atividade acadêmica para demonstrar
a utilização de HTML5, CSS3, GitHub e GitHub Pages.

## Tema escolhido

O tema escolhido foi **Gatos**.

A página apresenta informações sobre as características dos gatos,
algumas curiosidades e cuidados necessários para proporcionar
uma boa qualidade de vida aos animais.

## Tecnologias utilizadas

- HTML5
- CSS3
- Git
- GitHub
- GitHub Pages

## Recursos utilizados

A página utiliza:

- HTML semântico;
- Layout com CSS Grid;
- Design responsivo;
- Links com efeito `:hover`;
- Imagem com atributo `alt`;
- Listas ordenadas e não ordenadas;
- Caixa de citação;
- Menu de navegação;
- Cabeçalho e rodapé.
